# my-ai-journey

一个简单易用的命令行 AI 助手，基于 OpenAI SDK 与智谱 GLM 模型实现流式对话。

## 功能

- **安全输入 API Key**：启动时通过隐藏输入的方式读取 API Key，不再硬编码在代码中。
- **多角色切换**：支持三种 system prompt 角色：
  1. 编程老师
  2. 面试官
  3. 翻译
- **清空对话**：输入 `清空` 即可重置当前对话历史（保留当前角色）。
- **切换角色**：输入 `切换角色` 可随时更换 AI 角色并清空对话。
- **流式输出**：AI 回复实时逐字显示。

## 环境要求

- Python 3.8+
- 已安装 `openai` 包

## 安装依赖

```bash
pip install openai
```

## 运行方式

```bash
python chat.py
```

## 使用说明

1. 运行程序后，按提示输入你的 API Key（输入内容不会显示在屏幕上）。
2. 选择 AI 角色（输入编号 1/2/3，直接回车默认选择“编程老师”）。
3. 开始对话：
   - 输入问题，AI 会实时回复。
   - 输入 `清空`，重置当前对话历史。
   - 输入 `切换角色`，重新选择角色并清空对话。
   - 输入 `退出`，结束程序。

## 注意事项

- 请确保你的 API Key 有足够的额度访问 `glm-4.5-flash` 模型。
- 程序默认使用智谱 AI 的 `https://open.bigmodel.cn/api/paas/v4/` 作为 base_url，如需使用其他兼容 OpenAI 接口的服务，可修改 `chat.py` 中的 `base_url`。
